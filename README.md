# 🚀 Level 1 High-Power Rocket Certification Project



## Project Overview

Designed, assembled, integrated, tested, and successfully launched a high-power rocket to obtain Level 1 High-Power Rocket Certification.

This project served as an end-to-end aerospace systems engineering effort involving vehicle modeling, flight simulation, hardware integration, recovery system implementation, launch operations, and post-flight evaluation. Using OpenRocket for digital vehicle modeling and performance analysis, the project progressed from initial configuration and mission planning through final flight execution and recovery.

---

## Mission Objectives

- Achieve Level 1 High-Power Rocket Certification
- Develop and validate a safe and reliable rocket configuration
- Perform stability and flight performance analysis using simulation tools
- Integrate propulsion, airframe, and recovery subsystems
- Execute a successful certification flight
- Recover the vehicle in flight-worthy condition
